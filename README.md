# Solmara — Open-World Crime Sandbox

Entry for make.fun gta6-01 ("Make GTA 6"). A complete open-world crime game in the browser: 3D city, driving, car stealing, wanted system + police, 5 missions, combat, HUD with minimap, day/night cycle, procedural WebAudio sound. All art, sound and story original. No network requests at runtime.

Run: `npx tsx serve.ts` (or serve `game/` statically) and open the page.
